# Norse.Abstractions.Worker

Norse worker abstractions: `IWorkerHostPlugin`, command and cached repository surfaces (`ICommandRepository<T>`, `ICachedRepository<T>`), and NServiceBus handler contract seams — the server-side law for the system-of-record tier. Mutually invisible with `Norse.Abstractions.Web.Server`.

Part of the [Norse Architecture](https://github.com/NorseArchitecture) platform.
