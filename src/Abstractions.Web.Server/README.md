# Norse.Abstractions.Web.Server

Norse web-server abstractions: `IWebHostPlugin`, the document repository surface (`IDocumentRepository<T>`), mediator law (`ICommandRequest<T>`, `IRequestHandler`, `Outcome`, `Problem`, `ErrorCategory`, `BoolResponse`), and the `IDeferredSignIn` contract — the server-side law for the web tier. Mutually invisible with `Norse.Abstractions.Worker`.

Part of the [Norse Architecture](https://github.com/NorseArchitecture) platform.
