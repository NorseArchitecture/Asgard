# Norse.Abstractions.Web.Server

Norse web-server abstractions: `IWebHostPlugin`, the document repository surface (`IDocumentRepository<T>`), and mediator law (`ICommandRequest<T>`, validator and authorizer contracts) — the server-side law for the web tier. Mutually invisible with `Norse.Abstractions.Worker`.

Part of the [Norse Architecture](https://github.com/NorseArchitecture) platform.
